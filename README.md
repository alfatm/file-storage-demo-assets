# Cloud Demo Assets

A free asset set assembled to demonstrate a cloud file manager with folders,
previews, search, sharing and support for many file types.

## What is inside

The main dataset is in the `demo/` folder. It contains realistic sample files
in many formats:

- documents: PDF, DOCX, ODT, RTF, Markdown, HTML and TXT;
- images and design assets: JPG, PNG, WebP, SVG, GIF and PSD;
- archives: ZIP, TAR, 7z, gzip, bzip2, xz and other formats;
- resources: CSV, JSON, YAML, XML, SQLite, vCard and iCalendar;
- a small sample service used to demonstrate source-code browsing.

The set can be used as ready-made content for demos, prototypes, file-storage
UI testing and preview rendering checks.

## Purpose

The assets are arranged so the first load of a file manager feels like a real
workspace: folders, documents, photos, archives, spreadsheets, video and shared
files.

All people, companies, invoices and figures in the documents are fictional.
